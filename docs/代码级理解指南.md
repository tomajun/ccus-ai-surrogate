## 3. 主线 A 逐步拆解：0.0647 从哪几行来

**第 1 步 取数据。** `open_split(data_dir, "test")`（`repro/ufno/ufno_reader.py:118`）返回两个 memmap 视图：`a=(500,96,200,24,12)`、`u=(500,96,200,24)`。它不走 `torch.load`，而是自己解 pickle 元数据拿到**存储偏移与 stride**（`tensor_meta:65` + `_data_start:76`），再用 `np.lib.stride_tricks.as_strided` 造视图（`open_tensor:100`）。

> 为什么这么绕：`torch.load(..., mmap=True)` 在本机一旦参与运算就段错误；而 `sg_test_u.pt` 的 `u` 是**非连续的转置视图**（stride `(460800,200,1,19200)`），按 C 序朴素 reshape 会静默拿到错位的场，指标从 0.0647 变成 2.85 且**不报错**。这是本项目最贵的一个坑，代码注释在 `ufno_reader.py:12-20`。

**第 2 步 加载权重。** `eval_ufno_gas_saturation.py:70` 先调 `_expose_to_main()`（`:31`）再 `torch.load`。原因：官方权重是**整模型 pickle**、在 notebook 里保存的，类名被记成 `__main__.Net3d`；不把这些类注册进 `__main__`，反序列化会报 `Can't get attribute 'SimpleBlock3d'`。看到 `weights_only=False` 别改：torch≥2.6 默认 True，而整模型 pickle 必须关掉它。

**第 3 步 前向。** `:87` 一行三件事：`model(x)` → `Net3d.forward`（`ufno.py:203`）先补边（`:206`，竖向 +8 补 0、水平与时间 +8 replicate），六层后裁回并 `squeeze()`；`.view(-1, 96, 200, 24)` 是为了兜住 `squeeze()` 把 batch 维也吃掉的情况（batch=1 时输出少一维）。

**第 4 步 掩膜。** `:86` `mask = (x[:, :, :, 0:1, 0] != 0).repeat(1, 1, 1, 24)`：判据是**第 0 通道在 t=0 非零**，即"这一列是不是储层"；竖向只有 0~51 行是储层（52/96 = 54.17%），其余是上覆区哨兵 0。所有指标只在掩膜内算——这是"相对 L2 = 0.0647"这句话里"相对"和"掩膜内"两个限定词的来源。

**第 5 步 误差。** `:88` `myloss(pred[mask].reshape(1,-1), y[mask].reshape(1,-1))`，`LpLoss` 就是 `‖p−y‖₂ / ‖y‖₂`（`lploss.py:3`）。逐样本存进 `per_sample_rel_l2`，均值即 0.0647。

## 4. 主线 B 逐步拆解：区间和等级从哪几行来

`tools/run_uq_risk.py` 的 `main:98` 是唯一需要记住的入口，其余都是它的展开。按它内部的顺序，五段：

1. **基准 + K 副本**（循环体在 `main` 内，`predict:57` 负责一次前向）。每个场地跑 1 次基准 + `--replicas`（默认 8，`:105`）次扰动输入，得到 `(K+1, 96,200,24,12)` 的输入族。注意：**扰动的是输入通道，不是权重**，所以模型只加载一次。
2. **区间**：`mc_band`（`src/uq_model.py:112`）对 K 个副本求均值与标准差，`ddof=1`（样本方差）。扰动哪些通道由 `:38-41` 的常量决定：ch0/ch1（ln 渗透率）、ch2（孔隙度）、ch4（注入速率）、ch7（Swi）、ch8（λ）；ch3 井位、ch5/6 温压、ch9/10/11 网格坐标**不动**，因为它们是已知边界条件。噪声不是白噪声：`_correlated_noise:63` 用 `corr_len_cells` 做空间相关，模拟"同一区块渗透率一起偏高"这类结构性不确定。
3. **校准**：`band_coverage:157` 算 PICP/MPIW，`pooled_kappa:195` 在标定集上搜一个乘子 κ 使覆盖率达到 `1−alpha`（默认 0.90）。`min_band=0.01` 是防退化的地板：羽流外几乎处处为 0，若允许区间宽度为 0，覆盖率会被"零宽区间恰好盖住零值"这种假象推到 1。`calibrate_kappa:175` 是逐场地严格版，代价是区间宽到没有信息量（报告里 `per_site_strict` 那组 MPIW 0.656 就是这个证据）。
4. **指标与分级**：`extract_indicators`（`src/risk_model.py:305`）从预测场抽三轴——突破时间（`physical_time_days:284` 把 24 步换成物理天，`cumsum(1.421245^i)`，满程 ≈10,950 天 ≈30 年）、面积比、侧向逃逸比。`RiskReference:366` 拿真值分布做参照系（分位数），`classify_site:469` 同时给出点预测等级、区间等级与置信度，并在区间跨档时降级。**"确定档只占 33%"就是这一行的输出。**
5. **写产物**：json（报告，含 `field_band`/`indicator_conformal`/`tiers`/`axis_diagnostics`）、csv（逐场地表）、npz（前 10 个场地的场 + 500 个场地的标量）。**这三个文件是主线 C 的唯一输入**，也是答辩里所有数字的单一来源。

一句话总结 B：**"预测"来自模型，"区间"来自输入扰动，"等级"来自与真值分布的相对位置**。三者分别落在 `predict:57`、`mc_band:112`、`classify_site:469`。

## 5. `src/risk_model.py` 为什么有两代引擎同居一文件

| | LEGACY 部分 | CURRENT 部分 |
|---|---|---|
| 行号 | `RiskLevel:45`、`MECHANISM_NAMES:55`、`RiskConfig:66`、`assess:151` | `T_OUT:281` 起 |
| 输入 | 羽流场 + **人工给定的地质几何**（井点、断层线、盖层带） | 羽流场 + 掩膜 + 真值分布参照 |
| 逻辑 | 六条几何启发式规则，命中即报机制编号 | 三轴指标 → 分位数 → 点/区间双口径 |
| 谁在调 | 只有 `_selftest:529` 与 `src/risk_model_demo.py` | `tools/run_uq_risk.py`、`tools/make_figures.py`、`src/app/streamlit_app.py` |

真实数据集里**没有井位矢量、没有断层矢量、没有盖层深度**（ch3 只有一个稀疏注入点标记），所以几何引擎在真实数据上没有输入可给。这不是代码写坏了，是数据不支持——答辩里必须这样讲，别说成"实现了六机制"。

## 6. 把测试当考卷

`tests/test_uq_risk.py` 有 25 个测试，全部纯 numpy、不需要权重和数据集。它是这个仓库里**最省事的语义说明书**，每个测试名就是一句"这个函数在什么情况下必须给出什么结果"：

- conformal 与覆盖率（`:43 :51 :62 :70 :83 :93 :104 :128`）：`conformal_quantile` 的有限样本修正、`band_coverage` 的 PICP/MPIW 定义。
- 扰动与参数编辑（`:166 :178 :190 :205 :223`）：掩膜外不得被扰动、ch4/7/8 是时间曲线而非 3D 场、相关性噪声的方差量级；`edit_channels`（app 第⑥页用）与 `perturb_inputs` 必须同量纲——渗透率 ×1.5 就是对数通道加 ln(1.5)/15。
- 指标与时间（`:234 :246 :268 :279`）：`mc_band` 的无偏 std、`physical_time_days` 的单调与满程、突破时间的 NaN 语义（从未突破）。
- 分级（`:298 :312 :318 :329 :337 :354 :365 :374`）：跨档降级、反相关群体下的排序保持、退化参照系（分位数并列）时置信度归 0。

跑法：`.venv/Scripts/python.exe -m pytest tests/test_uq_risk.py -q`。想验证自己是否真懂某个函数，先删掉它的断言猜结果，再跑。

## 7. 十个动手练习（每条都有预期现象）

```bat
set PY=.venv\Scripts\python.exe
```

1. **形状**：`%PY% tools/ufno_internals_probe.py --model_path 数据集/sg_UFNO_4500_trained.pt --data_dir 数据集` → 打印逐层形状与参数账本；对照本文 §3。
2. **只看数据不动模型**：`%PY% -c "import sys;sys.path.insert(0,'repro/ufno');from ufno_reader import open_split;a,u=open_split('数据集','test');print(a.shape,u.shape,u.strides)"` → 看到 `u` 的 stride 不是 C 序，理解 §3 第 1 步。
3. **单样本前向**：把 eval 脚本加 `--limit 1`，在 `:87` 后打印 `pred.shape` → 理解 `.view(-1,...)` 为什么必须。
4. **随机权重**：eval 里临时用 `Net3d(10,10,10,36)` 不加载权重，`--limit 20` → rel L2 从 0.0647 掉到 ≈1.0~1.2。指标是权重学出来的，不是代码跑出来的。
5. **误读目标张量**：把 `u[i]` 按 C 序 reshape 再算 → 2.85、相关性 0.00。**不报错的错**最危险。
6. **κ 的作用**：`run_uq_risk.py` 加 `--kappa_cap 1`（关掉校准）→ 羽流区覆盖率从 0.911 掉到 0.868，区间变窄。校准买到的是"说到做到"。
7. **min_band 的作用**：把 `--min_band` 设成 0 → 看 `band_coverage` 的 PICP 如何被零宽区间虚假推高。
8. **副本数**：`--replicas 2` vs `8` → MPIW 明显变宽且不稳定，理解 K 是方差估计的代价。
9. **扰动通道开关**：在 `PerturbConfig:45` 把 `porosity_sigma` 设 0 重跑 → 区间收窄的那部分就是孔隙度贡献。
10. **砍 U-Net 分支**：注释 `ufno.py` 里 `x3 = self.unet3(x)` 三行并去掉 `+ x3` → 这是亲手量出 U-FNO 相对 FNO 增益的唯一办法；幅度必须自己实测，别引用别人的数。

## 8. 读代码时的九个坑（都是踩过的）

1. `sg_*_u.pt` 是**转置视图**，任何"直接 reshape"都会静默错位（§3 第 1 步）。
2. `torch.load` 必须 `weights_only=False`，且必须先 `_expose_to_main()`（`:31`）。
3. `Net3d.forward` 末尾 `squeeze()` 吃掉 batch 维，调用方一律 `.view(-1,96,200,24)`。
4. 掩膜定义在**输入第 0 通道的 t=0**，不是输出场大于 0；两者不等价。
5. 预测**没有 clamp**，会轻微越界（−0.0065~1.0024），算区间时别用 [0,1] 截它。
6. `mc_band` 用 `ddof=1`；改成 0 会让 K 较小时的标准差系统性偏小，覆盖率虚高。
7. `sat_thr=0.01` 定义"羽流区"，它同时影响面积比、侧向比和逐格覆盖率的口径——改它等于改指标定义，不是调参。
8. Windows GBK 控制台：脚本里 `sys.stdout.reconfigure(errors="replace")` 是必需的，否则一个生僻字符会中断整轮评估。
9. 报告文件名带 `_500` 的才是正式数字；`experiments/metrics_*.json` 是合成数据时代产物，`experiments_smoke.json` 是 1 样本冒烟测试（rel L2 2.849，就是坑 1 的历史现场）。
