  - **⚠️ 代码可得性修正（2026-10-15 PwC 复核）**：Zingaro 未检索到公开代码仓库，属「方法学复现」（自己按设置重做）。若你要「拉代码跑通」式复现，首选应改为 **U-FNO (Wen 2022, `github.com/gegewen/ufno`)**——有完整 Python 代码 + Google Drive 公开数据集，正是 FNO 升级版。详见 `docs/PapersWithCode复现候选.md`（含排序表+复现步骤+优化叠加点）。
  - **🚫 可行性修正（2026-10-29 实测）**：上文"4500 样本、本科 CPU 可跑"只对**推理**成立。训练集 ≈99.5 GB 本机放不下 → **复现 = 下载官方预训练权重 + test 集推理**，不自行训练。权威口径见 `docs/数据集与结题可行性审计.md` 第二、四节。
  - 理由：它直接在 **2D 单井 CO₂ 注入** 场景下对比 **U-Net / V-Net / TCN / FNO / U-FNO** 预测 CO₂ 饱和场与压力——这正是你 P1（CNN 基线）和 P2（FNO 进阶）要做的"多架构对比"，且 2D 轻量、输出就是 CO₂ 饱和场，和你 48×48 思路一致。
  - **核心结论（你要复现的靶子）**：U-FNO 在 CO₂ 饱和场预测上最准，FNO 在压力预测上最准；且性能强烈依赖底层 PDE 类型（双曲 vs 椭圆）。
- **"先复现再优化"是否可行：可行，但要分两层，且有个硬前提。**

- **关键诚实提醒**：你项目当前框架的输入是 **3 个标量参数 (Q, k, H)**，而 Zingaro/Yan 这类论文的输入是 **异质渗透率/孔隙度场图**。复现前者的"设置"需要把你的数据生成从"标量→场"升级为"异质场→场"，这是一笔明确的改造工作量，不是免费对齐。

## 一、首选论文详情

### Zingaro, G., Gracie, R., Leonenko, Y. (2026)
**A Comparative Study of Deep Learning Models for Geological Carbon Sequestration**
arXiv:2606.07215（University of Waterloo，2026-06-05 提交）

- **问题设置**：2D 域、单井 CO₂ 注入；参数化对象 = 各向异性异质渗透率场 + 孔隙度场 + 注入配置 + 储层属性；预测**瞬态压力场**和 **CO₂ 饱和场**。
- **对比架构**：U-Net、V-Net、TCN（时序卷积）、FNO、U-FNO（U-Net 增强的 FNO）。
- **核心结论**：
  - CO₂ 饱和场预测：**U-FNO 精度最高**；
  - 压力预测：**FNO 最好**；
  - 性能强烈依赖底层 PDE 类型（饱和是双曲型输运、压力是椭圆型）。
- **与你项目的契合点**：
  1. 直接覆盖你 P1（CNN/U-Net 基线）和 P2（FNO 进阶）的实验目标——它替你论证了"该用哪个架构"，你复现它就能直接拿到 baseline 对比图。
  2. 2D + 饱和场输出，和你 48×48 网格 + 饱和场输出天然匹配。
  3. 近期（2026），前沿感强，写进申报书"国内外研究现状"很有分量。
- **复现可得性**：⚠️ 未检索到官方开源代码仓库（arXiv 论文不强制附代码）。因此"复现"= 用你自己的框架按它的设置与结论重做，而非 clone 它的 repo。

## 二、备选论文（按相关度排序）

### 备选 1：Yan, B., Chen, B., Jia, W., Pawar, R. (2022)
**A robust deep learning workflow to predict multiphase flow behavior during geological CO₂ sequestration injection and Post-Injection periods**
Journal of Hydrology, 607, 127542. DOI:10.1016/j.jhydrol.2022.127542
- **内容**：基于 **FNO**，输入岩石性质 + 井操作控制 + 时间步，预测压力与 CO₂ 饱和度；分注入期/停注后期分别建模；**250× 加速**；3D 异质盐丘含水层。
- **契合点**：是你 FNO 进阶网络的**最直接学术对标**（同样用 FNO 做封存、同样预测饱和场）。
- **限制**：3D（比 2D 重），大概率无开源代码；作为"FNO 实现参考"而非"复现靶子"更合适。

### 备选 2：Chandra, A. et al. (2025)
**Fourier Neural Operator Based Surrogates for CO₂ Storage in Realistic Geologies**
arXiv（Anima Anandkumar 组）
- **内容**：FNO 实时高分辨率 CO₂ 羽流迁移，**O(10⁵) 加速**，含超分辨率实验；训练于"真实地下参数"综合数据集。
- **契合点**：FNO + CCS 的高水平代表，可作为你 FNO 方案的"上限参照"。
- **限制**：方法重、无确认开源代码。

### 备选 3：Ju, I. & Alahmed, A. (2024, Stanford CS231n)
**Learning CO₂ Plume Migration in Storage Reservoir using Neural Operators**
- **内容**：UFNO/FNO/CNO 在断层储层合成数据上预测 CO₂ 羽流序列（autoregressive），FNO 最佳、900× 加速。
- **契合点**：FNO 在封存羽流上的教学级清晰案例。
- **限制**：⚠️ 论文声称的代码仓库 `github.com/IsaacJu-debug/operator_co2_flow` 实测 **404（不可得）**。该作者另一仓库 `mgn_lstm` 是 GNN 路线，非 CNN/FNO。**不可作为代码复现源。**

### 备选 4（更贴你"标量参数→场"现状）：Wen et al. / Zhong et al.
- Wen et al.：R-U-Net，把注入时长/速率/位置编码为输入通道 → 饱和场（CNN 路线，贴近你当前输入表示）。
- Zhong et al. (UT Austin)：cDC-GAN 预测异质储层 CO₂ 羽流（GitHub `danilecug/CO2-GAN`，但数据来自商业软件 CMG、需邮件索取，复现成本高）。
- **契合点**：若你想"最小改动现有框架就复现"，Wen 的 R-U-Net 路线比 Zingaro 更贴（输入都是井操作参数）。但它是 CNN，不含 FNO，无法支撑 P2。

## 三、复现可行性评估（诚实版）

### 3.1 代码可得性真相
- 你方向（FNO + CO₂ 封存）的几篇核心论文，**大多没有可直接 fork 的开源代码**。
- Stanford CS231n 仓库已 404；Zingaro 未检索到代码仓库；Yan/Chandra 大概率无开源代码。
- **推论**："复现"在你这里 = **用你已有的框架，按论文的实验设置和结论重做一遍**，而不是拉别人代码跑。这其实是更好的学习方式（避免变成"跑别人 notebook 的搬运工"），但工作量由你承担。

### 3.2 你框架与论文的输入表示差距（最关键）
| 维度 | 你当前框架 | Zingaro/Yan 论文 |
|---|---|---|
| 输入 | 3 个标量参数 (Q, k, H) | 异质渗透率/孔隙度**场图** + 注入配置 |
| 输出 | 48×48 饱和场（单帧） | 饱和场 + 压力场（瞬态多帧） |
| 物理 | 玩具高斯羽流合成器 | 多孔介质多相流（有 PDE 依据） |

- **含义**：要"严格对齐 Zingaro 的设置"复现，你必须把 `sim/synthetic_field.py` 从"标量→场"升级为"**生成异质渗透率场 + 用简化数值/解析模型生成对应饱和场**"。这是 P5（多保真度）之前的必要升级，也是真实数据锚（你已落地的 NATCARB 先验）能发挥作用的地方。
- 若只做"方法复现"（不改输入表示，仍用标量参数），则只能复现"FNO 优于 CNN 这一大类结论"，无法逐指标对齐 Zingaro 的数字——但作为本科大创的 baseline 已够用。

### 3.3 你的现有优势
- 已有 `synthetic_field` + `make_dataset` + `cnn_surrogate` + `fno_surrogate` + `train.py`，骨架完整。
- NATCARB 真实参数先验已落地并 GO（`data/priors.json` 已启用）。

## 四、"先复现再优化"是否可行——分阶段结论

### 硬前提（必须先完成）
本机装好 torch（CPU 版），跑通 `tools/run_local_pipeline.bat`，拿到 `models/*.pt` 与 `experiments/metrics_*.json`。**这一步没做，复现无从谈起。**

### 阶段 A：方法复现（低风险，建议先做）
- 用现有框架，按 Zingaro 的架构清单（至少 U-Net/CNN vs FNO）训练，产出 **P1/P2 的 baseline 对比图**（预测对比图 + 误差表）。
- 目标：拿到"在你的数据上，FNO 是否如 Zingaro 所说优于 CNN"的第一手结论。
- 产出：`results/cnn_vs_fno_compare.png` + `experiments/metrics_cnn.json` / `metrics_fno.json`。
- **可行性：高。** 因为不需要改数据管线，直接复用现有 48×48 合成数据。

### 阶段 B：设置复现（中风险，需改数据管线）
- 把 `synthetic_field.py` 升级为"异质渗透率场生成 + 简化饱和场生成"，严格对齐 Zingaro 的 2D 单井 CO₂ 注入设置。
- 目标：能逐指标对比 U-FNO/FNO 在你的实现上的精度，与论文数字交叉验证。
- **可行性：中。** 工作量集中在"异质场生成 + 简化物理模型"，约 1–2 周；且能顺便补上你红队评审指出的"风险无真值/数据无锚"短板（异质场比标量参数更有物理依据）。

### 阶段 C：优化（在你复现基础上叠加创新点）
- **创新① UQ**：在阶段 A/B 训好的 surrogate 上跑 `train_uq.py`，给预测加 ±区间（PICP/MPIW）。Zingaro 没做 UQ，这正是你的差异化。
- **创新② 多保真度**：用阶段 B 生成的"低保真（简化模型）" + 少量"高保真（PorePy/ Kimberlina 切片）"做残差校正。
- **风险模块**：把你已写的 `sim/risk_proxy.py`（通道专属风险）接入，替代旧循环论证打分。
- **可行性：高（建立在 A/B 之上）。** 你的三个创新点都是"在已训 surrogate 上叠加"，不依赖复现论文本身。
