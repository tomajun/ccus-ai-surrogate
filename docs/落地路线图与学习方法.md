# CCUS-AI-Surrogate 落地路线图与学习方法

> 本文档回答三件事：**① 框架怎么搭、先跑通什么；② 创新点怎么一步步做出来；③ 怎么用 AI 但不被代写、还能学到东西。**
> 它和 `实验方案.md`（科研设计/申报书用）互补：那份讲"为什么这么做、指标是什么"，这份讲"你动手怎么做、怎么学"。
> 适用前提：本科大创，周期约 12–18 个月，个人/2–3 人小队，AI 作为协作者而非代笔。

---

## 0. 先对齐三件事（读这份方案前必读）

### 0.1 这个项目为什么"不能靠 AI 几次做完"
它不是"写一个脚本"的大小，而是**一个完整科研闭环**：数据→模型→风险→不确定性→多保真度→演示→文档→答辩。
任何一环都能单独拿出来说事。所以本方案刻意把工程切成 **8 个阶段、每个阶段 3–6 个可独立交付的小步**。
**关键心态**：你不需要一次做完。做完 Phase 1–3 就已经是一个"能演示的 baseline"，足够撑中期检查；做到 Phase 5 就是带两个创新点的成品。几次做不完不是失败，是正常节奏。

### 0.2 你用 AI 的正确姿态（学，不是甩）
- **AI 是"结对程序员 + 评审"，不是"代写机器"。**
- 判断标准：每个阶段结束，你能否**不查资料、用自己话**讲清核心概念，并说清你写的代码每一段干嘛。能，就是学到了；不能，就是被代写了。
- 本文档第 7 节给出具体"三级用 AI 法"和"禁区"。

### 0.3 仓库现状盘点（框架已经搭好一半）
| 文件 | 职责 | 你当前要做的 |
|---|---|---|
| `sim/synthetic_field.py` | 合成羽流生成器 + 风险打分 | 读懂，不动 |
| `sim/make_dataset.py` | 批量造数据 → `data/synthetic.npz` | 跑通 |
| `sim/export_to_numpy.py` | 高保真数据(MRST/PorePy)转统一格式 | Phase 5 才用 |
| `src/dataset.py` | PyTorch Dataset，读 .npz | 读懂 |
| `src/models/cnn_surrogate.py` | 基线代理(UNetLite) | Phase 1 跑通 |
| `src/models/fno_surrogate.py` | 进阶代理(FNO) | Phase 2 跑通 |
| `src/models/risk_classifier.py` | 风险三档分类(RiskMLP) | Phase 3 跑通 |
| `src/train.py` / `src/train_risk.py` | 训练脚本 | 跑通 + 后期加 UQ |
| `src/app/streamlit_app.py` | 网页演示（当前：读真实管线产物，5 页） | Phase 6 打磨 |
| `tests/test_synthetic.py` | 数据管线测试 | 每阶段都跑 |

**结论**：骨架（数据、模型、训练、演示、测试）都在了。你的工作不是"从零写"，而是"读懂 → 跑通 → 给两个创新点加肉"。这正好适合边学边做。

## 1. 框架搭建：先把骨架跑通（Phase 0，约 1–2 周）

### 1.1 建环境（一次性）
```bash
cd ccus-ai-surrogate
python -m venv .venv
.venv\Scripts\activate        # Windows；Mac/Linux 用 source .venv/bin/activate
pip install -r requirements.txt
```
> 沙箱/机房若装不上 torch：用你自己的笔记本（CPU 即可，网格仅 48×48）。这是设计时就定好的"轻量"原则。

### 1.2 数据契约（全项目最重要的约定，必须背下来）
所有数据都收口成一个 `.npz` 文件，三个键：
| 键 | 形状 | 类型 | 含义 |
|---|---|---|---|
| `fields` | `(N, T, H, W)` | float32 | N 个样本、T=10 个时间步、H=W=48 的 CO₂ 饱和度场 |
| `params` | `(N, 3)` | float32 | 每行 `[注入速率 Q, 盖层渗透性 k, 储层厚度 H]` |
| `risks` | `(N,)` | int64 | 风险标签 0/1/2（低/中/高） |

**为什么重要**：下游 `dataset.py`/`train.py`/`train_risk.py` 全部只认这三个键。你以后加高保真数据、加 UQ，都只改"怎么造这个 .npz"，**不动模型读取逻辑**。这就是框架的"插座标准"。

### 1.3 第一次跑通（命令清单 + 预期）
```bash
python sim/make_dataset.py --n 800 --out data/synthetic.npz   # 造数据，约几十秒
python -m src.train --model cnn --epochs 5                     # 先 5 轮试水，看能跑
pytest tests/                                                  # 测试应全过
```
预期：`data/synthetic.npz` 生成；训练打印 loss 在下降；`TESTS PASSED`。

### 1.4 Phase 0 学习验收（过不了就先别进 Phase 1）
- 能画一张图解释：`fields[i, -1]` 是什么（最终时刻的羽流分布图）。
- 能说清 `params` 三个数分别对应现实里的什么物理量。
- 能解释"为什么代理模型要预测的是整张场，而不是一个数字"（提示：风险分级依赖空间形态）。

## 3. Phase 1–3：打地基（约 4–6 周）

> 这阶段**不要追求创新**，先把"标准科研流程"走顺。地基牢，创新才好加。

### Phase 1 — 基线代理 CNN（UNetLite）
- 任务：`python -m src.train --model cnn --epochs 20`，看测试集 RMSE/SSIM。
- 学习点：① 什么是图像到图像的回归；② 训练循环（loss/optimizer/epoch）；③ SSIM 为什么比 MSE 更"像人眼"。
- AI 用法（二级）：让 AI 用伪代码讲训练循环 5 步，**你**照着读 `train.py` 并给每行加中文注释。
- 交付：`models/surrogate_cnn.pt`、`experiments/metrics_cnn.json`、一张"预测 vs 真值"并排图。

### Phase 2 — 进阶代理 FNO
- 任务：`python -m src.train --model fno --epochs 20`，对比 CNN。
- 学习点：① 傅里叶变换把"空间"变"频率"；② 谱卷积学的是"算子"而非"固定网格像素"——所以 FNO 能泛化到不同分辨率/外推。
- AI 用法：让 AI 用比喻讲"CNN 记的是位置，FNO 记的是规律"，然后你读 `fno_surrogate.py` 的 `SpectralConv2d`。
- 交付：`models/surrogate_fno.pt` + 对比表（FNO 应在"外推测试"上优于 CNN）。

### Phase 3 — 风险分级 RiskMLP
- 任务：`python -m src.train_risk --epochs 30`，看 Accuracy / Macro-F1。
- 学习点：① `featurize()` 把一张场压成 8 个特征（为什么能压？因为风险看的是"铺展范围/集中度"）；② 类别不平衡要用宏平均。
- 交付：`models/risk_mlp.pt` + 混淆矩阵图。

## 4. ★创新点①：不确定性量化（UQ）（约 3–4 周）

### 为什么它是真创新
评审眼里，"泄漏风险"若只给一个档位（低/中/高），是**点估计**，决策方不敢用。给**置信区间**（"高风险，置信 85%"）才是安全决策需要的。2024–2026 年 GCS 领域 UQ 是热点（Seabra 2024 *IJGGC*、Lu 2025 *WRR* 等），但本科项目里几乎没人做——这就是你的差异化。

### 怎么做（落地路径，二选一或叠加）
- **路径 A · 深度集成（最易上手）**：用**不同随机种子训 5 个 CNN/FNO**，预测取均值、标准差即不确定性。`train.py` 改成循环训 5 次存 5 个权重。
- **路径 B · MC Dropout**：在模型里加 `Dropout`，推理时开 dropout 跑 20 次取统计。改动小，但需理解"dropout 在测试期为何能估不确定性"。
- 风险分级的 UQ：训 5 个 RiskMLP，预测概率的熵 = 不确定性（"模型自己也不确定"）。

### 指标（写进申报书/答辩）
- **PICP**（Prediction Interval Coverage Probability）：真实值落在 90% 区间里的比例，越接近 0.9 越好（区间要准）。
- **MPIW**（Mean Prediction Interval Width）：区间平均宽度，越窄越好（区间要紧）。
- 风险：报告"高风险的样本中有多少模型自己也拿不准"。

### 学习验收
能讲清：为什么不确定性在"安全"场景比"精度"更重要；PICP 和精度(SSIM)是两件不同的事。

## 5. ★创新点②：多保真度代理（约 4–6 周）

### 为什么它是真创新
你现在的数据是**合成**的（教学级）。要让人信"你的代理能用于真实封存"，得证明它能**借少量昂贵的高保真仿真样本校正自己**。这正是 NRAP 项目（Bianchi 2016 *IJGGC*）的经典思路：用链接函数把低保真和高保真桥接。

### 怎么做（落地路径）
1. **低保真（已有）**：`synthetic_field.py` 造大量样本（便宜）。
2. **高保真（少量）**：用 `sim/export_to_numpy.py` 接 PorePy（纯 Python，本科友好）或 CO₂ DataShare 的 Sleipner 模型，跑 **20–50 个**昂贵样本（贵，所以少）。
3. **桥接模型**（核心创新代码）：
   - 方案 1：先在低保真上训基础代理，再训一个小"校正网络"学 `高保真−低保真` 的残差（delta correction）。
   - 方案 2：输入加一个 `fidelity` 标志位，让网络同时见两种数据（multi-fidelity NN）。
4. **指标**：只用 N=20 个高保真样本时，桥接模型相对"纯低保真"的 RMSE 下降多少；对比"若不用低保真、只拿 20 个高保真直接训"的误差。

### 顺手提质（零成本）：NATCARB 真实参数
把 `synthetic_field.py` 的均匀采样，改成按 NATCARB（NETL，CC BY 4.0）的真实孔隙度/渗透率分布采样。答辩时可直接说"参数分布取自公开北美封存数据库"——说服力瞬间不同，且不涉及任何涉密数据。

### 学习验收
能讲清：低保真和高保真的关系像"草图 vs 精修图"；为什么用少量精修图校正草图，比纯靠精修图更省。

## 6. 卫星创新（可选，锦上添花）

- **XAI / SHAP（最易、答辩出图）**：对 RiskMLP 做特征归因，回答"为什么这个场地是高风险？"输出一张特征重要性条形图 + 几个反例。半天能出。
- **主动学习（最贴"降本"叙事）**：用代理的不确定性，自动挑"最该跑一次高保真仿真"的参数点，形成"不确定→仿真→补数据→再训"的循环。呼应创新②的"高保真很贵"。

## 7. AI 协作纪律（重点：怎么用 AI 还不丢学习能力）

### 三级用 AI 法（按阶段升级）
- **一级（只问概念）**：「用大白话讲清楚 FNO 为什么比 CNN 适合预测物理场」→ 你听、记、**合上对话自己复述一遍**。
- **二级（要思路不要代码）**：「给我这个训练循环的伪代码/步骤，不要写完整代码」→ **你**照着写，`train.py` 已存在，你读它、改它。
- **三级（审代码）**：「这是我写的，挑 3 个可改进点，别直接改」→ **你**改。

### 禁区（踩了就是被代写，学不到）
- ❌ 一次性让 AI 输出整个模块然后你复制粘贴。
- ❌ 看不懂的代码也提交（评审一问就露馅，且你没成长）。
- ❌ 让 AI 替你想"创新点是什么"——创新方向由你定（本方案已定①②），AI 只帮你实现。

### 反向费曼法（每阶段收尾必做）
关掉 AI，打开一个 `学习笔记.md`，**不查资料**写下：这个阶段的模型/方法一句话是什么、我写的代码哪段对应哪步、我卡过哪里怎么解决的。写不出来 = 没学会，回去补一级用 AI 法。

## 8. 时间节奏建议（按学期拆，承认它大）
- **第 1 学期**：P0 → P3（基线+进阶+风险，可演示，够中期）。
- **第 2 学期**：P4（UQ）+ P5（多保真度）+ P6（演示/文档/答辩）。
- **假期/延伸**：P7 卫星创新、3D/多井扩展、投稿本科论坛。
> 周期可压缩到 1 年（删 P7、P5 做简版），也可延到 1.5 年（P5 做实、加 3D）。按你学校大创要求调。

## 9. 你随时可以停在哪（降低焦虑）
- 停在 P3：一个"CNN/FNO 代理 + 风险分级"的完整 baseline，中期没问题。
- 停在 P4：多一个 UQ 创新点，结题够用。
- 停在 P5：两个创新点齐备，竞争力强。
- 每一停都有可运行代码 + 指标 + 图，不是半成品。
