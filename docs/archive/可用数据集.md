## 0. 一句话推荐（本科生最可行路线）
1. **主力数据**：继续用仓库自带 `sim/synthetic_field.py` 合成（零依赖、CPU、零涉密），但把 `sample_params` 的**均匀采样改为按 NATCARB 真实地质分布采样**（见 C 类），成本几乎为零、真实感显著提升。
2. **进阶对标**：用 **CO₂ DataShare 的 Sleipner 基准储层模型 + PorePy** 跑少量高保真饱和场，经 `sim/export_to_numpy.py` 混入训练/测试，做"合成 vs 高保真"泛化验证（README 第 7 节路线）。
3. **真实数据亮点（可选）**：向 EDX 申请 **Kimberlina 1.2 CO₂ 饱和场**许可后用作主训练集；或用 Sleipner 4D 地震做监测演示（注明数据归属 Equinor、代码仅借鉴）。

## 接入契约（与 `sim/export_to_numpy.py` 对齐）
统一输出 `.npz` 三键，**`train.py` / `train_risk.py` / `dataset.py` 零改动即可吃**：
- `fields` : `(N, T, H, W)` float32  ← CO₂ 饱和度时空序列（最终帧作预测目标）
- `params` : `(N, 3)` float32        ← `[injection_rate, caprock_perm, thickness]`
- `risks`  : `(N,)` int64           ← 0/1/2（由 `risk_score` 自动打标）

当前 `export_to_numpy.py` 已支持 **`.mat` / `.npy` / `.npz`**；A1(Kimberlina, `.npz`)、B3(MRST `.mat`) 可直接转；A2(GEOS 自定义) 与 A3(SEG‑Y 地震) 需写适配读取（A3 还需先做地震反演，模态不同）。

## 推荐落地路线（按本科生可行性排序）
1. **零成本提质**：把 `sim/synthetic_field.py` 的 `sample_params` 改为按 **NATCARB(C1)** 真实分布采样 → 答辩时可直接说"参数分布取自公开北美封存数据库"，说服力 +1。
2. **高保真对标（进阶）**：下载 CO₂ DataShare 的 **Sleipner 基准储层模型**，用 **PorePy(B2)** 跑数十个高保真饱和场，经 `export_to_numpy` 混入，验证代理模型在真实物理上的泛化（README 第 7 节）。
3. **真实数据亮点（强但非必需）**：Kimberlina(A1) 本质是**合成的高保真仿真**数据（非真实测量），物理可信且无涉密风险，最贴近 surrogate 目标。EDX 公开下载后，邮件联系 EDX 数据集页列出的 POC **确认许可**（本档不留他人邮箱）即可作主训练集；或以 Sleipner 地震(A3) 做监测演示（注明 Equinor 归属）。**注意：即便拿不到 Kimberlina，项目也不缺数据**——见第 0 节推荐路线。
