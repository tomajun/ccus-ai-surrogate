> 本文回答两个问题：(1) 真实数据怎么拿；(2) 数据增强 + RAG + 大模型**正确**怎么用。
> 配套代码：`sim/augment.py`（经典增强）、`data/priors.json`（真实先验骨架）、`sim/make_dataset.py`（已升级读先验）。

## 0. 先给结论（含批评）

1. **真实数据获取**：优先走「NATCARB 真实参数先验 + CO₂ DataShare/PorePy 高保真 + Kimberlina（可选需许可）」三条公开路径，详见第 1 节。**绝不引入任何涉密真实油田数据。**
2. **「用大模型/RAG 直接扩充真实数据」是陷阱，必须反对**——详见第 2.1 节三条硬理由（物理不可信、学术诚信红线、技术自欺）。
3. **RAG + 大模型的正确用法**：把它当「领域知识检索与抽取引擎」，从真实文献里抽出**物理参数先验分布**，再喂给我们的合成器 `sample_params`，让合成数据在统计意义上贴近真实封存案例。这是可信、可辩护、且本身就是一个创新点——「知识引导的数据合成」。详见第 2.2 节架构。
4. **经典数据增强**（第 3 节）：对已有场数据做轴对称翻转、时间插值、测量噪声建模等物理保持变换，扩容且不失真。已落到 `sim/augment.py`，沙箱可跑。

一句话：**真实数据走公开源；绝不用 LLM 造场数据，而是用 RAG 抽真实物理先验喂合成器，再叠加经典增强。**

## 1. 真实数据获取路径（按本科生可行性排序）

### 路径 A（零成本 · 推荐先做）：用 NATCARB 真实分布校准合成器
- **来源**：NATCARB / EDX（NETL），北美沉积盆地 10km 网格的孔隙度、渗透率、深度、厚度、封存容量（P10/P50/P90）。许可：**CC BY 4.0**（需署名 NETL）。
- **怎么拿**：注册 [edx.netl.doe.gov](https://edx.netl.doe.gov) → 检索 `natcarb-alldata` / `saline-basin-10km-grid` → 下载 CSV/GeoTIFF → 提取目标盆地（如 Permian、Gulf Coast）的孔隙度/渗透率/厚度统计（均值与分位数）。
- **怎么用**：把 `sim/make_dataset.py` 的 `sample_params`（现为 `uniform`）改为从这些真实分布采样。仓库已为此预留接口——`data/priors.json` 写好后把 `"enabled": true` 打开即可（详见第 2 节）。
- **效果**：答辩原话「输入参数分布取自公开北美封存数据库 NATCARB（CC BY 4.0）」——零成本、零涉密、可信。

### 路径 B（进阶 · 高保真对标）：CO₂ DataShare 的 Sleipner 基准模型 + PorePy
- **来源**：SINTEF CO₂ DataShare（开放获取，各数据集自带许可与署名）。
- **怎么拿**：注册 [geoscience-central.com/databases/co2-datashare](https://www.geoscience-central.com/databases/co2-datashare) → 下 Sleipner 基准储层模型（ECLIPSE deck / Petrel）→ 用 **PorePy**（纯 Python，LGPL/MIT）跑数十个 2D 注入场景饱和场。
- **怎么用**：`.npy/.npz` → `sim/export_to_numpy.py`（已支持）转统一 `.npz` → 混入训练/测试做「合成 vs 高保真」泛化验证（README 第 7 节路线）。
- **代价**：需学 PorePy、跑仿真（CPU 可，但比合成慢）。许可：Sleipner 模型署名 SINTEF/NCCS；PorePy 代码可复用。

### 路径 C（强但需许可）：Kimberlina 1.2 3D 饱和场
- **来源**：EDX/NETL（LBNL「SMART」倡议），33 个时间戳 3D CO₂ 饱和场 + Python 读取脚本。
- **怎么拿**：EDX 申请；License Not Specified → **参赛/发表前必须取得明确许可，或仅内部教学使用**。
- **怎么用**：取 2D 切片 → `export_to_numpy.py`（已支持 `.npz`）→ `train.py`。最贴近 surrogate 目标。
- **风险**：许可不确定，不可直接当主训练集商用。

### 路径 D（真实监测演示，可选）：Sleipner 4D 地震
- **来源**：Equinor 公开 4D 地震；`nusbei/CO2_Sleipner`（9★，但**代码无 LICENSE**）。
- **怎么用**：模态是「地震→CO₂ 存在」，与「参数→饱和度」不同，不能直接当 surrogate 目标；可作监测演示，或先做反演再接 risk 分类。
- **许可**：地震必须署名 **Equinor**；代码不可复用，仅借鉴方法。

**合规红线**：绝不引入任何涉密真实油田/封存监测数据；以上均为公开或合成数据。

## 2. RAG + 大模型的正确打开方式（重点）

### 2.1 为什么「LLM 直接造数据」是陷阱（三条硬理由）
1. **物理不可信**：LLM 不懂多孔介质流动，生成的饱和度场/参数数组是「看起来像数字的幻觉」，违背质量守恒、浮力规律 → 训练出的代理模型学到假物理。
2. **学术诚信红线**：大创/论文中把 LLM 生成的数值当「真实/仿真数据」使用，属数据伪造，一经发现项目作废。
3. **技术自欺**：代理模型的 RMSE/SSIM 会被假数据「刷」好看，但一到真实场景（PorePy/MRST 验证）立刻崩——答辩专家用 Sleipner 一比就露馅。

### 2.2 正确架构：知识引导的数据合成（Knowledge-Grounded Synthesis）
RAG 的角色是**「读真实文献、抽出真实物理统计」**，不是「造数据」。流程：

```
真实文献/报告 (PDF/网页，含 Sleipner/Utsira 等公开案例)
   │  入库（切分 + 向量化）
   ▼
RAG 知识库（向量索引）
   │  query：「Sleipner 注入速率/埋深/渗透率/盖层渗透性范围？」
   ▼
LLM 抽取结构化参数先验 {param: 分布/区间/典型值 + 出处}
   │
   ▼
写入 data/priors.json（可审计、可引用出处、可辩护）
   │
   ▼
sim/make_dataset.py 的 sample_params() 改用先验采样   ← 已升级，读 priors.json
   │
   ▼
合成器产出「统计上贴近真实案例」的训练样本（物理仍一致）
```

- **好处**：(a) 数据仍物理一致（来自合成器）；(b) 参数统计来自真实文献（可引用）；(c) 全程可审计；(d) 本身即创新点——「基于检索增强的领域知识引导合成数据」。
- **第二种合法用法（LLM 当场景生成器）**：让 LLM 把自然语言场景（如「高渗浅层咸水层」「低渗深埋构造」）映射到参数区间，再交给合成器生成——仍是「诚实生成」，不伪造场数据。

### 2.3 落点与前置依赖
- 新增 `data/priors.json`：存放 RAG 抽取的真实参数先验（含出处 URL）。
- 新增 `rag/build_knowledge.py`：读文献目录 → 切分 → 向量化（需 embedding 后端）→ 存索引。
- 新增 `rag/extract_priors.py`：检索 top-k → 调 LLM 抽取结构化先验 → 写 `priors.json`。
- `sim/make_dataset.py` 的 `sample_params`：已升级为「读 `priors.json`，无则用 uniform 兜底」（见仓库当前代码）。
- **前置依赖**：RAG 需要 embedding + LLM 后端。当前环境**未配置任何 LLM API Key**（Tavily 也无）。需你提供 **DeepSeek / OpenAI / 本地 Ollama** 任一的 key 或本地服务地址。代码会写成后端可插拔（环境变量切换）；**没有 key 也能跑通 uniform 兜底**，不阻塞现有流程。

## 3. 经典数据增强（物理保持，适用于本项目数据契约）

**数据契约**：`fields (N,T,48,48)` 饱和度场，`params (N,3)` = [injection_rate, caprock_perm, thickness]。
以下增强都**不改物理规律**，只扩样本/提鲁棒性。已落到 `sim/augment.py`。

| 方法 | 操作 | 适用/注意 |
|---|---|---|
| ① 轴对称翻转 | 沿注入轴（grid 中央 x0=grid_n/2）左右翻转 fields | 域对称时严格成立，样本×2；**最稳** |
| ② 时间插值 | 相邻时间步间线性插值插入帧（T 翻倍） | 物理平滑，扩时序样本；末帧变化需谨慎对待标签 |
| ③ 参数微扰重采样 | 对已有 params 加 ±5% 高斯扰动，越界则重生成 field | 扩参数空间覆盖；合成器便宜，等价于多采样 |
| ④ 测量噪声建模 | field 加小幅高斯噪声（σ≈0.01），clip 回 [0,0.85] | 模拟地震/井数据噪声，提鲁棒性；不可过大 |
| ⑤ 多分辨率自监督 | 48→24 降采样作输入、48 作目标，构造 SR 配对 | 不直接增样本，可作辅助预训练任务 |
| ⑥ MixUp/CutMix（谨慎） | 两样本按 λ 线性混合 field 与 param | **有物理风险**（混合场未必物理合理），仅可选实验 |

- **推荐默认组合**：① + ④（flip + noise）作为批量增强；② 按需单独调用；③ 靠「多采样」自然覆盖；⑤⑥ 可选。
- **代码落点**：`sim/augment.py` 的 `augment_dataset()`（flip+noise 默认开）、`time_interp()`、`add_noise()`、`flip_axis()`、`mixup()`。
- **标签处理**：flip/noise 不改变末帧物理语义，risk 标签可保留；time_interp 改了末帧，建议保留原标签（保守）或在下游按末帧重算。
