## 一、结论（先说清楚）

1. **数据不缺。** 真正堵死的只有 EDX 一个数据源（需 `.gov/.mil` 邮箱或 NETL 担保人），而它恰好是最不重要的——它是地球物理**监测集**，不是代理模型要预测的羽流流场。其余可用数据均**免登录或仅需 Google 账号**：
   - U-FNO 作者 Google Drive 的 4500 样本 `.pt`（开箱即用，单点但可达）；
   - CO₂ DataShare / Sleipner 2019 模型（Open，免账号，真实项目标杆）；
   - NATCARB 参数先验（已落入 `data/priors.json`，文献统计，非登录）；
   - GitHub `clastic_shelf_GEOS` / `3DFNO_GCS`（免登录，需自跑模拟器造数据）。

2. **方向可做，但必须改定位。** 不能宣称"首创代理模型"。合理定位是（2026-10-30 按实际做到的修订）：
   **"复现 SOTA 的 U-FNO 代理（官方权重推理，指标 0.0647），叠加'参数扰动 + 保形校准'的不确定性量化，串联跨样本相对口径的封存风险三档筛查排序"**。
   这是本科生大创站得住的增量，不是前沿首创，但扎实、可答辩、可复现。
   ~~深度集成~~ 已不可行：官方只放 1 组权重，K 个成员必须自训，而训练集 99.5 GB 本机放不下 —— 这条要在答辩里主动交代成"取舍"。

3. **能否正常结题 = 三道门同时过**（详见第三节）。**门 1（数据）、门 2（算力）已于 2026-10-30 本机实测通过；只剩门 3。** 最危险的不是技术，而是**导师是否接受"复现+改进"作为结题标准**——这件事必须你本周去问。

4. **合成数据路线（阶段 A + 阶段 B）已被实验证明是死路（已验证，2026-10-17）。**
   - 阶段 A（同质）CNN 的 SSIM 仅 0.0106、UQ 的 PICP 仅 0.7%~24%。
   - 阶段 B（异质 k 场作为输入）我**原假设"把 perm 场喂进模型就能解锁 UQ"**，但后台实验结果推翻了它：模型直接学成**全零预测器**（验证集预测均值=0.0000、>0.01 像素占比=0.0%、crude_ssim=0.0069），5 个种子收敛到同一解 → PICP_95=0.081、MPIW≈1.4e-10（仍坍缩）。
   - **根因（已验证的双重问题）**：① 数据——合成羽流只占约 15% 网格且取值小，MSE 损失被 85% 零背景主导，模型"回归到均值 0"、没有动力学羽流；② UQ 方法学——原脚本让 K 个种子训在完全相同的数据上，确定性数据必然收敛到同一函数。第 ② 点已修（加 bootstrap 重采样），但第 ① 点在合成数据上无解。
   - **结论：合成数据只能作为"管线冒烟测试 + 负面诊断"（证明弱信号下点预测与 UQ 都会崩，可写进 limitations），绝不能当作"方法有效"的验证。** 项目的真实验证**只能来自 U-FNO 真实 4500 样本数据集**（U-FNO 原文在该数据上达到 R²>0.99，信号确实存在）。

**数据格式（2026-10-30 直接读 `.pt` 内 `data.pkl` 的 size/stride 元数据核定）：**
- 后缀 `.pt` = PyTorch 序列化的张量文件（二进制），**不是图片**。
- 输入 `sg_*_a.pt`：size `(N, 96, 200, 24, 12)` float32，stride `(5529600, 57600, 288, 12, 1)` → **C 连续**。
- 输出 `sg_*_u.pt`：size `(N, 96, 200, 24)`，stride `(460800, 200, 1, 19200)` → **非连续的转置视图**：
  内存里实际按 **(时间 24, 竖向 96, 水平 200)** 排布。
  - 轴序 = (竖向 96, 水平 200, 时间 24, 通道 12)；物理尺度竖向 0–200 m、水平约 3500 m（`dx=cumsum(3.5938×1.035012^i)+0.1`），时间 24 步为 `cumsum(1.421245^i)` 天（约 30 年）。
  - **此前文档写的 `(N,3,200,96,24)` / "输入 3 通道 / 输出 1 通道" 是错的**（轴序与通道数双错），已按实测更正。
  - 12 个通道的含义（`SimpleBlock3d` 注释 + 官方 eval notebook 的反归一化式，已用实测值域核对）：
    ch0/ch1 = ln 水平/垂向渗透率（`kr=exp(ch×15)` mD）、ch2 = 孔隙度、ch3 = 注入位置、
    ch4 = 注入速率、ch5 = 温度、ch6 = 压力、ch7 = Swi、ch8 = 流度比 λ、ch9/10/11 = 水平/竖向/时间格距。

**实测发现的四个硬约束（都直接影响路线）：**
1. **训练集下不动**：`sg_train_a.pt` 按 4500 样本推算 ≈ **99.5 GB**，而本机 C 盘剩余不足、内存 15.8 GB。
   → **"本机/Colab 复现训练"这条路线不成立**，改走**官方预训练权重 + test 集推理**。
2. **`torch.load(mmap=True)` 在本机不可用**：能读到正确 shape，但对该张量做任何读取/运算（`clone`、`!=0`、`np.array`）**一律 Segmentation fault**。
   → 已在 `repro/ufno/ufno_reader.py` 改为按字节偏移 `np.memmap` + **按元数据 stride 用 `as_strided` 还原**，已实测可用。
3. **输出张量必须按 stride 还原，否则复现直接失败**（本轮最大的坑）：
   把 `sg_test_u.pt` 按 `(96,200,24)` 朴素 reshape，等于把羽流错位重排 —— 与模型预测相关性 **0.00**、rel L2 **2.85**；
   按真实 stride 还原后相关性 **0.993**、rel L2 **0.0647**。**这类错误不会报错，只会给出一个看起来"差不多"的坏指标。**
4. **`sg_val_u.pt` 9.2 GB 之谜已解**：它的 `storage_offset = 2,073,600,000` 个元素 = **4500 个样本**，
   即整个 storage 是 `train 输出(4500) + val 输出(500)` 拼在一起，保存的是尾部视图；之前猜"上游塞了 5000 个样本所以不自洽"是错的。
   → 走权重推理路线本就不需要 val，**可删 `数据集/sg_val_*.pt` 释放约 20 GB**（待你决定，未擅自删除）。

## 五、阶段 B 实验结论（已验证，2026-10-17）：合成数据路线终止

**已构建（沙箱可跑，未依赖外部数据）：**
- `sim/synthetic_field_b.py`：异质渗透率场（多尺度 GRF + 对数正态 + 盖层密封 + 井筒提渗）+ 重力舌主干 × 异质调制生成羽流。selftest 已通过：异质差异从阶段 A 的 ~0.0008 提升到 **0.0148**（近 20 倍），羽流范围 13.6%。

- `src/train_b.py`：深度集成 UQ 验证（K 种子 → PICP/MPIW），**已加 bootstrap 修正**。

**实验结果（后台跑完，非假设）：**

| 阶段 | 模型 | 输入 | val_RMSE | crude_SSIM | PICP_95（目标≈0.95） | MPIW | 结论 |
|---|---|---|---|---|---|---|---|
| 阶段 A（同质） | CNN | 3 标量 | — | 0.0106 | 0.2432 | 0.0 | 崩溃 |
| 阶段 A（同质） | FNO | 3 标量 | — | 0.0466 | 0.0071 | 0.0058 | 崩溃 |

**由此得出的关键判断（不粉饰）：**
- 合成数据（阶段 A/B）**不能**作为"方法有效"的验证，只能作为管线冒烟测试 + 负面诊断（写进 limitations 章节："在弱信号/稀疏羽流数据上，点预测与 UQ 均失效"）。
- 项目的真实验证**只能来自 U-FNO 真实 4500 样本数据集**——该数据上 U-FNO 原文达到 R²>0.99，信号确实存在。
- **阶段 B 代码保留但冻结**：作为"正确管线结构"（4 通道输入）的参考，等你拿到真实数据后可复用其输入结构，但不在合成数据上继续投入。
- UQ 方法学缺陷（确定性数据上集成坍缩）已修复：在 `train_uq.py`/`train_b.py` 给每个集成成员加** bootstrap 重采样**，使稀疏区产生非平凡方差。该修复将在真实数据上生效。

## 七、增量定位（答辩时能讲清"你的贡献"）

纯复现 U-FNO 太薄，答辩会被问"你的贡献是什么"。文献给出两个有支撑、可行的增量，且正好对应已写好的模块：

- **增量 A（最稳，有 2025 两篇 SPE 论文背书）：** 在 U-FNO 上加**不确定性量化**。U-FNO 原文只做点预测、无校准区间——这就是你的空档。
  **状态：已实现（2026-10-30）**，但路线从"深度集成"改成"**输入侧参数扰动 MC + split conformal 校准**"：集成要自训 K 个成员，而官方只放 1 组权重、训练集 99.5 GB 本机放不下。代码在 `src/uq_model.py`，一条命令跑通在 `tools/run_uq_risk.py`。
- **增量 B：** 把"代理 + 风险三档 + UQ"串成**封存风险筛查排序**工作流（对标 Velasco Lozano 2025 接 NRAP-Open-IAM）。
  **状态：已实现同一口径的三级判级**（`src/risk_model.py` 的相对分位 + 区间判级 + 可信度降级）。**注意措辞**：本数据集没有井位/断层几何，所以交付的是"封存风险筛查排序"，**不是"泄漏/盖层失效预警"**——这条边界要一直守住。

**诚实预期：** 这是"复现 + 改进"型大创，不是前沿顶会成果；但可以是扎实、可答辩、甚至投国内本科生论坛/会议海报的项目。
