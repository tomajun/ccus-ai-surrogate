# 项目背景调研问题清单

> 用法：每题给出**一句话答案 + 一条证据**。证据只能是四类之一：文献（页码/公式号）、代码（文件:行号）、本机实测（脚本 + 数字）、官方数据文档原文。
> 优先级：**P0** = 答辩必答，答不上就是硬伤；**P1** = 答上能提升结论强度；**P2** = 拓展视野，被追问再答。
> 凡是标注「待查证」的，说明本项目目前没有可靠依据，不要凭 README 旧口径或印象作答。

## B. 物理模型：控制方程与假设

| # | 问题 | 优先 | 合格答案的样子 |
|---|---|---|---|
| B1 | 描述地下 CO₂ 运移的守恒方程组是什么（质量 / 动量 / 能量）？每一项的物理含义、耦合方式？ | P0 | 能写出达西定律 + 多相流质量守恒 + 组分输运，并说明本项目对应等温还是非等温 |
| B2 | 这套数据用了哪些简化：是否耦合地质力学？是否含地球化学/矿物反应？两相还是多相？毛细压力与相对渗透率用的是什么模型（Corey / van Genuchten）？ | P0 | 逐条列出"有/无/待查证"，并说明每个简化在 30 年时间尺度上会不会失效 |
| B3 | CO₂ 在地下的四种捕获形式（构造、残余/毛细、溶解、矿物）各在什么时间尺度主导？模型输出的 Sg 属于哪一种？ | P0 | 关键结论：Sg 是**自由气相饱和度**，只覆盖构造捕获那部分；溶解与矿物捕获不在输出里 |
| B4 | 浮力、黏性指率 λ、毛细压力分别控制羽流的什么形态？λ 大意味着什么？为什么数据把 λ 单列成 ch8？ | P0 | 能画出"黏性驱替 vs 浮力主导"两种羽流形状，并对应到我们的 fig 图 |
| B5 | 为什么水平渗透率与竖向渗透率要分开给（ch0/ch1）？kz/kr 比值如何改变竖向突破的难易？ | P0 | 结合实测：ch0/ch1 是 ln 后除以 15 的归一化值，各向异性来源就是这两通道 |
| B6 | 束缚水饱和度 Swi（ch7）为什么重要？它怎么影响残余捕获量与有效储集空间？ | P1 | 一句话机制 + 一个敏感性证据（UQ 里扰动 ch7 后区间的变化幅度） |
| B7 | 工程上"注入压力不超过地层破裂压力"这条硬约束怎么量化？本项目模型覆盖它了吗？ | P0 | 明确答"没有"：数据集无井筒、无盖层力学、无破裂压力场 → 这是已知边界，不是缺陷隐瞒 |
| B8 | 我们的网格是竖向 96 层、水平 200 格（格距 3.6 m → 3,386 m，累计 ≈100 km）、时间 24 步（≈30 年）。这个尺度对应现实中的场地级还是盆地级？哪些物理在这个尺度上被粗化了？ | P1 | 需要说清"前缘亚网格细节不可分辨"，这直接解释模型为何偏平滑 |
| B9 | 时间轴为什么是非均匀、指数加密（cumsum(1.421245^i)）？说明物理上哪个阶段变化最快？ | P1 | 答"早期"，并指出这对误差分布的影响（早期帧误差占比更高还是更低，需实测） |
| B10 | 输入里的压力、温度（ch5/ch6）是**静态初始场**还是**仿真中间时刻的结果**？这一点决定了模型是否"偷看了答案"。 | P0 | **待查证**（必须回到原始论文/数据说明，不能靠猜）。若为仿真产物，要说明它在部署时是否可获得 |
| B11 | 哨兵 0 掩膜为什么存在？它说明数据集是"裁剪过的储层窗口"而非全模型？对指标计算有什么影响？ | P0 | 已实测：竖向 52/96 = 54.17% 为储层，其余是上覆区哨兵 0；所有指标只在掩膜内计算 |

## G. 文献查证动作清单（把上面的「待查证」关掉）

对每篇文献，只提取三件事：**物理假设 / 数据集来源与实验设计 / 指标口径**。

1. U-FNO 原文（Wen 等，Advances in Water Resources，2022）→ 关 B2、D4、E2。
2. FNO 原文（Li 等，ICLR 2021）→ 关 D1、D3 的原始出处。
3. 该数据集的**数据描述论文**（模拟器、参数分布、样本设计）→ 关 B10、C1、C2、C3。**这是最关键的一篇，本项目目前缺它的一手依据。**
4. 一篇封存项目的监测/监管综述 → 关 F1、F2。
5. 一篇算子学习在多孔介质流的应用综述 → 关 D5 的竞品淘汰理由。

规则：
- 每篇先在本清单登记"读到的具体位置"，再写答案；没读到原文不引用。
- 所有引用与 `docs/文献真实性查验清单.docx` 交叉核对，避免引入不存在的文献。
- 结论变化要同步回 `docs/U-FNO模型讲解与答辩准备.md` 与两份 PPT，数字口径只允许一个来源。
