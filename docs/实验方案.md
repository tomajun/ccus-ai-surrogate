# 实验方案（CCUS-AI-Surrogate）

> 用于申报书"研究内容与技术路线""可行性分析""预期成果"章节，以及中期/结题考核。

## 1. 实验目标
验证"AI 代理模型可在保证精度的前提下，大幅加速 CO₂ 封存羽流预测，并给出可靠泄漏风险分级"。

## 2. 数据方案
- **数据源**：内置合成模拟器 `sim/synthetic_field.py`（参数空间见下表），生成 800~2000 组 (注入参数 → 10 步时空羽流场)。
- **参数空间**：
  | 参数 | 符号 | 范围 | 含义 |
  |---|---|---|---|
  | 相对注入速率 | Q | 0.5–2.0 | 注得越快，羽流越大 |
  | 盖层渗透性 | k | 0.1–1.0 | 越大越易横向铺展/泄漏 |
  | 储层厚度 | H | 20–40 | 网格单位 |
- **划分**：按 8:1:1 随机切分 训练/验证/测试（固定 `seed=42` 保证可复现）。
- **替换路径**：高保真用 MRST（MATLAB）或 PorePy（Python）导出 numpy 样本，接口不变。

## 3. 模型与基线
| 模型 | 类型 | 角色 |
|---|---|---|
| 线性回归/常量基线 | 统计 | 最低参照（预测全场均值） |
| UNetLite (CNN) | 深度学习 | **主基线** |
| FNO (傅里叶神经算子) | 深度学习 | **进阶创新** |
| RiskMLP | 深度学习 | 泄漏风险三档分类 |

## 4. 评估指标
- **回归（羽流场）**：RMSE（逐像素）、SSIM（结构相似度，贴近"肉眼像不像"）、MAE。
- **分类（风险）**：Accuracy、Macro-F1（类别不平衡所以用宏平均）、混淆矩阵。
- **效率**：单样本推理延迟（ms）、相对"逐帧仿真"的概念加速比（论文标注为概念性）。

## 5. 实验设计（消融与对比）
1. **主对比**：CNN vs FNO，在测试集比 RMSE/SSIM，验证进阶模型泛化更优。
2. **消融 A（参数贡献）**：仅用 Q / 仅用 k / 全部参数，看哪些注入参数对预测最关键（呼应可解释）。
3. **消融 B（网格分辨率）**：48×48 vs 64×64，看分辨率—精度—速度权衡。
4. **外推测试**：训练用 Q≤1.5，测试用 Q∈(1.5,2.0)，验证模型对"未见过的强注入"是否仍能预测（FNO 预期优于 CNN）。
5. **风险分级**：在 FNO 预测场上跑 RiskMLP，报告 Macro-F1 与混淆矩阵。

## 6. 结果记录与可视化（`results/`）
- 预测 vs 真值 并排图（多场景）
- 误差热力图（|pred−truth|）
- 风险混淆矩阵
- 指标表（CSV/JSON，写入 `experiments/metrics_*.json`）

## 7. 里程碑（12–18 个月大创周期建议）
- **M1–M3**：环境搭建 + 合成数据管线 + 基线 CNN 跑通（可演示）。
- **M4–M6**：FNO 进阶 + 风险分级 + 指标对比。
- **M7–M9**：可解释分析 + 网页演示 + 中期检查。
- **M10–M12**：高保真数据替换（可选）+ 论文初稿 + 结题材料。
- **M13–M18**（国创延伸）：多井/3D 扩展、与 MRST 对标、投稿本科论坛/普通期刊。

## 8. 风险与兜底
- 若 FNO 训练不稳定 → 以 CNN 结题，FNO 列为"已探索的进阶方向"。
- 若算力不足 → 全程 48×48 + CPU，已验证可跑。
- 若需"真值"说服力 → 引入 MRST 小算例做少量高保真对标。
