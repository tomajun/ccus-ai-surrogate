## 二、可借力的基础工具（非 CCUS 专属）
- [fatiando/verde](https://github.com/fatiando/verde) (671★)：空间数据网格化（地球科学）。

- `PorePy`（SINTEF，Python 开源）：裂缝性储层仿真，高保真数据替代方案。

## 三、差异化结论
CCUS 的"AI 代理建模 + 泄漏风险智能评估"细分在 GitHub 上**近乎空白**（相关仓 24–29 个、多为 0–8★ 仿真/材料）。本项目切入蓝海，天然差异化，且紧扣双碳国家战略。
