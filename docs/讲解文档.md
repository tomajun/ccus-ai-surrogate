# 讲解文档（直白版，带比喻）

> 给队友/评审/你自己复习用。不堆术语，能用大白话+比喻说清就绝不绕弯。
> 配套代码在仓库根目录：`sim/`、`src/`、`tests/`。

---

## 1. 这个项目到底在干嘛？
**一句话：教 AI 当"CO₂ 封存预测员"。**

国家要减碳，办法之一是把工厂排的 CO₂ 抓起来，压到地下几千米的岩层里"锁住"（这叫 CCUS）。但 CO₂ 压进去之后会像**墨水滴进海绵**一样，在岩层里慢慢扩散、上浮，形成一团叫"羽流（plume）"的东西。工程师想知道：它会不会飘到盖层、会不会漏？传统办法是用超算做数值仿真，慢且贵。

我们做的事：**用一堆"注入方案 → 羽流结果"的例子，训练一个神经网络，让它学会这套规律。以后只要输入注入参数，它秒级就能画出羽流、并告诉你泄漏风险高不高。** 相当于把"请专家算三天"变成了"问 AI 一秒钟"。

## 2. 数据从哪来？会不会涉密？
**全部自己用代码"造"，不碰任何真实油田/封存数据。**

真实封存监测数据（比如 4D 地震）又涉密又稀缺。所以我们写了一个 `sim/synthetic_field.py`：**一个被大幅简化的 2D 羽流模型**——它按物理直觉（CO₂ 会浮、会铺、盖层越松越易漏）生成一堆"长得很像真的"羽流样本。

比喻：这就像为了练投篮，先用纸箱摆个迷你篮筐练手感；真上场再换标准篮筐（MRST/PorePy 高保真仿真）。论文里要诚实写清"这是教学级代理数据"，但**方法和模型是真实的、可直接替换真数据**。

## 3. 代理模型是什么？（两个版本）
"代理模型"= 用一个快模型去替掉那个慢仿真。我们有两个：
- **CNN 基线（`cnn_surrogate.py`）**：像一个有经验的绘图员，**照着参数"画"**羽流图。稳、好训，是底线。
- **FNO 进阶（`fno_surrogate.py`）**：像学生**不背图，而是"悟出了物理规律"**——它在频率域学算子，所以碰到没见过的注入方案，泛化更稳。这就是我们强调的"进阶创新点"。

比喻：CNN 是"看样例临摹"，FNO 是"掌握公式后举一反三"。答辩时这套对比很加分。

## 4. 泄漏风险分类器（`risk_classifier.py`）
代理模型负责"画羽流"，分类器负责"看图安检"。它把三件事综合打分：
- 羽流是不是贴着盖层（顶部饱和高 = 危险信号）
- 是不是摊得很大一片
- 盖层本身渗透性高不高

最后吐出三档：**低/中/高**。比喻：它是"看完 X 光片给出风险预警的医生"。

## 5. 怎么把整个东西跑起来（命令清单）
```bash
pip install -r requirements.txt
python sim/make_dataset.py --n 800 --out data/synthetic.npz   # 造 800 份样本
python -m src.train --model cnn --epochs 20                    # 训基线
python -m src.train --model fno --epochs 20                    # 训进阶(可选)
pytest tests/                                                  # 跑测试
streamlit run src/app/streamlit_app.py                         # 开网页演示
```
**最低配置：一台普通笔记本 + CPU 就能跑**（网格只有 48×48，模型很小）。

## 7. 评审/队友最常问的坑
- **"数据是假的，论文算数吗？"** → 方法真实、模型真实、可一键换真数据；合成数据在参赛与教学中被广泛接受（参考 `Beckybams/AI-for-Carbon-Capture-Optimization` 用合成工业数据的做法）。
- **"FNO 太难，训不动？"** → 基线 CNN 保底，FNO 是加分项；设了早停，跑不动就先交 CNN 版。
- **"和 GitHub 上项目重复吗？"** → 检索显示 CCUS 的 AI 代理+风险评估细分几乎空白（24~29 个相关仓，多为仿真/材料），我们天然差异化。

## 8. 给本科生的学习顺序建议
1. 先跑通 `sim/synthetic_field.py` 的 `__main__`，**看懂数据长什么样**（打印 shape、画一张图）。
2. 再读 `dataset.py` + `cnn_surrogate.py`，理解"输入参数、输出场"。
3. 跑 `train.py` 看 RMSE/SSIM 数字变化，建立"模型好坏"的直觉。
4. 最后才碰 FNO 和 Streamlit 演示。
