## 幻灯片 1 · 封面
- 标题：基于 AI 代理建模的 CO₂ 封存羽流快速预测与泄漏风险智能评估
- 副标题：CCUS 方向 · 国家级/省级大学生创新创业训练计划
- 关键词：双碳、CCUS、神经算子、开源、可复现

## 幻灯片 2 · 背景与意义（30 秒）
- 双碳战略下 CCUS 是必选项；封存安全性论证依赖数值仿真，**慢、贵、难比选**。
- 一句钩子："把工程师算三天的活，变成 AI 一秒的回答。"

## 幻灯片 3 · 研究痛点
- 真实仿真：小时~天级，难支撑选址比选与实时安全评估。
- 真实数据：涉密、稀缺 → 我们用**开源合成数据**解决（零合规风险）。

## 幻灯片 4 · 国内外现状与差异化（关键，评奖加分）
- GitHub 检索：CCUS 相关 ML 仓库仅 20~30 个，且多为仿真/材料；"AI 代理 + 风险评估"细分**近乎空白**。
- 我们定位：**蓝海、首做、契合双碳**。

## 幻灯片 5 · 技术路线
- 图：数据(合成) → 代理模型(CNN/FNO) → 风险分级 → Web 演示。
- 强调：全部开源、Python、CPU 可跑。

## 幻灯片 6 · 核心创新点
- A：傅里叶神经算子代理建模（泛化优于 CNN）
- B：泄漏风险智能三档分级
- C：交互式开源演示 + 可解释
- 对比 GitHub 同类：几乎无直接对手。

## 幻灯片 7 · 已落地成果（现场演示！）

- 展示指标表（RMSE/SSIM/延迟/加速比）。
- 强调：代码、数据脚本、图表、申报文档**全量开源托管**。

## 讲稿要点（每页 3 句核心）
- **S2**：国家要减碳，CO₂ 要封地下；但"封得安不安全"算起来太慢，这是真痛点。
- **S4**：我们在 GitHub 上数过，这个细分方向几乎没有成熟的 AI 开源项目——这就是我们的机会。
- **S7**：**不念代码，直接演示**。让评委看到"滑块一动，羽流就出来，风险立刻评级"。
- **S9**：我们不是只写论文，而是做出一个能跑、能演示、能复现的开源仓库。

## 答辩高频问答预案
- Q：数据是合成的，结论有效吗？→ 方法/模型真实，可一键换 MRST/PorePy 高保真数据；合成路径学术认可。
- Q：和现有仿真比谁更准？→ 代理模型不追求更准，追求"足够准且快 1000×"，用于比选与初筛。
- Q：FNO 是什么，难吗？→ 在频率域学算子的神经网络，泛化更好；我们有 CNN 保底。
- Q：涉密风险？→ 全程合成/公开数据，零涉密。
